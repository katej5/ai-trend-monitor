# AI 동향 모니터

AI 기사·논문 목록(CSV)을 넣으면 `rules.js`에 적힌 기준대로 5개 주제로 분류하고, 출처 신뢰도와 중요도를 매겨 대시보드로 보여 주는 웹페이지입니다. 신흥기술영향평가세미나(2026-2) 2인 1조 실습으로 만들었습니다.

## 배포 주소

| 누구 | 주소 | 배포 방식 |
|---|---|---|
| 소유자 (@LoveEvaLee) | https://loveevalee.github.io/ai-trend-monitor/ | 팀 저장소 main · Pages |
| 팀원 (@katej5) | https://katej5.github.io/ai-trend-monitor/ | 팀원 fork main · Pages |

팀원 fork는 팀 저장소 main이 바뀌어도 저절로 따라오지 않습니다. fork 첫 화면에서 **Sync fork → Update branch**를 눌러야 반영되므로, 두 주소의 화면이 다르면 이것부터 확인합니다.

주소를 열면 예시 데이터가 자동으로 들어가 바로 대시보드가 그려집니다. 서버도, 도구 안 AI 호출도 없는 정적 페이지라 `index.html`을 더블클릭해서 열어도 똑같이 동작합니다.

## 무엇을 보여 주나

| 화면 | 내용 |
|---|---|
| 요약 숫자 | 총 건수 · 분류됨 · 미분류 · 건너뛴 줄(빈 줄·날짜 없음·날짜 형식 오류, 줄 번호 표시) |
| 주제별 개수 | 주제 5개 + 미분류 막대. 막대를 누르면 주별 추이에 그 주제 선이 더해짐 |
| 주별 추이 | 월요일 시작 주별 꺾은선. 7일이 덜 찬 첫 주·마지막 주는 점선 |
| 주제별 중요도 순위 | 주제마다 중요도 상위 5건. 등급에 마우스를 올리면 출처 유형과 근거가 보임 |
| 기간별 키워드 순위 | 90일 · 30일 · 7일 · 전날 탭, 직전 같은 기간 대비 증감 |
| 미분류 목록 | 어느 주제에도 걸리지 않은 기사 → 분류 사전에 키워드를 더할 후보 |
| 내보내기 | CSV(다시 넣으면 같은 결과) · 마크다운(요약 보고용) |

## 사용법

1. 배포 주소를 열거나 `index.html`을 더블클릭합니다. 예시가 자동으로 분석됩니다.
2. 내 자료를 보려면 CSV를 입력 칸에 붙여 넣은 뒤 **분석**을 누르거나, **파일 선택**으로 고르면 바로 분석됩니다.
3. CSV 형식은 첫 줄 머리글 `date,title,url,source`, 날짜는 `YYYY-MM-DD`, 인코딩은 UTF-8입니다. 제목에 쉼표가 있으면 큰따옴표로 감쌉니다. 아래는 형식만 보여 주는 예입니다.

```csv
date,title,url,source
2026-10-16,"EU AI Act enforcement begins, first RFIs sent",https://digital-strategy.ec.europa.eu/en/news/example,europa.eu
```

기준일은 컴퓨터 날짜가 아니라 **입력 데이터의 마지막 날짜**입니다. 그래서 같은 입력은 언제 열어도 같은 결과가 나옵니다.

## 판단 기준 (`rules.js`)

판단 기준은 모두 `rules.js` 한 파일에 있고, js 코드는 이 파일을 읽어 적용만 합니다. 기준을 바꿀 때는 이 파일만 고치고 PR로 검토합니다. 자세한 적용 방식은 파일 맨 위 주석에 있습니다.

- **주제 5개**: AI 에이전트 · AI 거버넌스·공공 AI · AI 리터러시·교육 · 피지컬 AI·로보틱스 · 파운데이션 모델. 주제마다 한·영 키워드와 제외어가 있고, 한 기사에 주제가 여러 개 붙을 수 있습니다.
- **출처 등급 (146개 도메인)**: A 동료심사 학술지·학회, 정부·국제기구 / B 프리프린트·주요 언론 / C 기업 발표·전문가 글·코드 저장소·작은 인터넷 매체 / D 커뮤니티. 도메인마다 근거를 한 줄씩 적었고, 등급표에 없는 도메인은 C로 두고 표시합니다.
- **중요도** = 등급 가중치(A 3 · B 2 · C 1 · D 0.5) × (1 + 같은 날 비슷한 기사 수) × 최신성(14일마다 절반)
- **키워드**: 형태소 분석기 없이 등록한 구("EU AI Act" 등)를 먼저 묶고, 조사를 떼고, 불용어·서술어·크기 표기를 뺀 뒤 기사 수로 셉니다.

주제 선정 근거는 [AI부문_후보.md](AI부문_후보.md), 수집처 후보와 신뢰도 평가는 [수집처_평가.md](수집처_평가.md), 기획 전체는 [기획안.md](기획안.md)에 있습니다.

## 확인한 결과

예시 입력(`data/example.csv`, 2026-07-09 ~ 10-16, 기사·논문 116건 + 시험용 줄 2개)의 기대 결과를 [data/expected.md](data/expected.md)에 적어 두고, 화면 결과를 이 값과 대조했습니다.

| 항목 | 기대값 | 화면 |
|---|---|---|
| 총 건수 · 분류됨 · 미분류 · 건너뛴 줄 | 116 · 103 · 13 · 2 (40번 빈 줄, 80번 날짜 없음) | 같음 |
| 주제별 개수 | 에이전트 22 · 거버넌스·공공 AI 23 · 리터러시·교육 20 · 로보틱스 25 · 파운데이션 모델 31 | 같음 |
| 전날 키워드 상위 3개 | 로봇 2 · 브릴스 2 · AI 에이전트 1 | 같음 |
| 중요도 1위 | 114번 줄 · 2.00 | 같음 |
| 내보낸 CSV 다시 넣기 | 처음 결과와 같음 | 같음 (2회 왕복) |

기대값은 파이썬 기준 계산, 리뷰어의 자바스크립트 구현, 실제 도구 코드 세 가지를 서로 따로 짜서 맞춰 보았고, 기사 116건 × 항목 9개에서 차이가 없었습니다.

## 한계

- **'비슷한 기사'가 예시에서 한 건도 잡히지 않습니다.** 겹침 기준(키워드 2개)이 높아서 지금 중요도는 사실상 '등급 × 최신성'입니다.
- **A등급 기사가 상위에 잘 오르지 않습니다.** 학술지·정부 문서는 날짜가 오래된 경우가 많아 최신성에서 밀립니다.
- **한·영 같은 말을 따로 셉니다** ('humanoid'와 '휴머노이드').
- **활용형이 키워드로 남습니다** ('요청하면', '찾고'). 형태소 분석 없이 조사만 떼기 때문입니다.
- **도메인 단위 등급**이라 같은 사이트 안의 글 성격 차이(기업 블로그와 모델 카드 등)는 구분하지 못합니다.
- 키워드에 걸리는지로만 분류하므로 키워드가 없는 기사는 미분류로 남습니다. 미분류 목록은 분류 사전을 보강할 후보로 씁니다.

## 협업 방식

모든 변경은 브랜치 → PR → 상대 리뷰·승인 → 병합으로 들어갔습니다. PR 본문은 **에이전트가 한 일 · 사람이 판단한 지점 · 확인한 방법** 세 칸으로 쓰고, 리뷰어는 직접 실행하고 기대값·손 검산과 대조한 뒤 승인했습니다. 리뷰에서 나온 의견(숫자가 붙은 모델 이름, 특수 하이픈, 조사 떼기 조건 문구, 날짜 형식 검사 등)은 같은 PR이나 다음 PR에 반영했습니다. 코드와 문서 작성에 Claude Code를 썼고, 판단과 확인은 사람이 했습니다.
